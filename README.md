# Instagram Raftar Clone

Flutter recreation of the supplied Instagram Raftar APK interface.

## GitHub build

Push this folder to a GitHub repository. The included GitHub Actions workflow builds a release APK automatically.

1. Create a repository.
2. Upload/push all files in this folder.
3. Open **Actions** -> **Build Android APK**.
4. Run the workflow.
5. Download the `instagram-raftar-release` artifact.

The original APK is Flutter-compiled, so this project is a visual recreation rather than a byte-for-byte copy of the original application.
